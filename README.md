# Sudoku (Flutter)

Тренировочный проект для изучения Flutter и алгоритмов на Dart.
Простая игра «Судоку 9×9» с несколькими режимами генерации головоломок,
карандашными пометками, сохранением прогресса и Material 3 темой.

> ⚠️ **Это учебный пет-проект.** Код написан для практики, а не для
> продакшена. Архитектура сознательно простая — без state management
> библиотек, без DI, без codegen. Всё держится на `StatefulWidget`
> и трёх-четырёх файлах логики.

---

## Возможности

- **Режимы игры:**
  - **Обычный** — решений может быть несколько, но головоломка всегда решаема.
  - **Одно решение** — классический судоку с проверкой уникальности.
  - **Логический** — каждый шаг можно сделать без угадывания
    (используются только Naked Singles и Hidden Singles).
  - **С проигрышем** — те же правила, что в «Одно решение», но после
    3 ошибок партия завершается.
- **Карандашные пометки** — сетка кандидатов внутри клетки.
- **Автосохранение** — прогресс не теряется при закрытии приложения.
- **Счётчик ошибок** и подсветка неверно введённых цифр.
- **Подсветка строки, столбца и блока** выбранной клетки.
- **Material 3** тема с градиентами и скруглениями.

## Технологии

- **Flutter** (стабильный канал, Dart 3)
- **Material 3** — тема генерируется из одного seed-цвета
- **shared_preferences** — единственная внешняя зависимость, для сохранений

Никаких пакетов для state management, навигации, DI или codegen —
всё написано «руками» ради учебной ценности.

## Как это работает

### Генерация головоломки

1. Backtracking-решатель заполняет пустое поле полностью — получаем
   валидное решение.
2. Из решения удаляются клетки в случайном порядке.
3. После каждого удаления головоломка проверяется «судьёй», в зависимости
   от режима:
   - **Обычный** — оставляем удаление до достижения ~20% подсказок.
   - **Одно решение / С проигрышем** — `countSolutions(...) == 1`.
   - **Логический** — `solveLogically(...)` возвращает `true`.
4. Если проверка не прошла — клетка восстанавливается.

Такой подход гарантирует, что каждая головоломка **решаема**
(потому что мы вырезаем клетки из готового решения) и удовлетворяет
критерию режима.

### Логический решатель

Применяет только две тактики, повторяя их до упора:

- **Naked Single** — у клетки остался ровно один возможный кандидат.
- **Hidden Single** — цифра может встать только в одну клетку
  в строке, столбце или блоке.

Если после всех итераций поле не заполнено — головоломка требует более
сложных тактик или угадывания, и отбрасывается.

## Сборка и запуск

```bash
# Установка зависимостей
flutter pub get

# Запуск на подключённом устройстве / эмуляторе
flutter run

# Сборка релизного APK
flutter build apk --release --split-per-abi
```

APK появятся в `build/app/outputs/flutter-apk/`.
Для современных телефонов нужен `app-arm64-v8a-release.apk`.

## Известные ограничения

- **Только 9×9.** Код модели параметризован под любой размер блока `n`,
  но UI и меню зафиксированы на `n = 3`. Расширение до 16×16 требует
  доработки отрисовки мелких цифр и более быстрого решателя.
- **Логический режим** знает только Naked/Hidden Singles. Для сложных
  головоломок этого мало — существуют пары, X-Wing, Swordfish и др.
- **Режим «Обычный»** не проверяет, что головоломка не имеет ситуации
  «50/50» в неоднозначных клетках. Технически решение может отличаться
  от того, что хранится в `solution`, и такое будет помечено как ошибка.
